# Skills comerciais da ACME · como usar

> Dados fictícios para treinamento. Skill-gabarito (mestre roteadora).

## O processo em 30 segundos
Funil: Qualificação → **Diagnóstico** → Proposta → Follow-up → Contrato → Handoff CS. Metodologia: Challenger (ensinar, adaptar, conduzir). Regra que mais pesa: nenhuma proposta sem **custo do problema em reais** confirmado no Diagnóstico. Handbooks em `04-handbooks/`.

## Mapa das skills
| Skill | Quando usar | Status |
|---|---|---|
| `acme-como-usar` | Sempre primeiro (esta) | ✅ |
| `acme-contexto` | Portfólio, ICP, personas, provas, vocabulário da ACME | ⏳ a gerar de `contexto-empresa.md` |
| `acme-metodologia` | Metodologia Challenger: elementos E1–E8, escala 0–3, critério de cada etapa | ⏳ a gerar de `02-metodologia/metodologia.md` |
| `acme-qualificacao` | Primeira reunião: hipótese (Warmer), reframe, agendar o diagnóstico | ⏳ handbook pendente |
| `acme-diagnostico` | Preparar, conduzir, registrar e revisar o Diagnóstico | ✅ |
| `acme-proposta` | Montar e apresentar a proposta a partir do custo do problema | ⏳ handbook pendente |
| `acme-negociacao` | Objeções de preço, piloto, concessões planejadas, contrato | ⏳ handbook pendente |
| `acme-handoff-cs` | Passar contexto, critério de sucesso e riscos ao CS | ⏳ aguarda entrevista de CS |
| `acme-coaching` | Coaching de uma call: transcrição × rubrica da etapa | ⏳ |

## Qual ler para cada tarefa
| Tarefa | Leia, nesta ordem |
|---|---|
| Preparar um diagnóstico | `acme-diagnostico` (Preparar) → `acme-contexto` → `acme-metodologia` |
| Registrar um diagnóstico no CRM | `acme-diagnostico` (Registrar) |
| Decidir se o negócio pode ir para Proposta | `acme-diagnostico` (Revisar) |
| Cliente pediu preço por hora | `acme-diagnostico` (objeções) → `acme-negociacao` |
| Coaching de uma call | `acme-diagnostico` (modo Revisar) → `acme-coaching` quando existir |
| Dúvida de portfólio ou ICP | `acme-contexto` |

## Regras para todas as skills
- Nunca inventar número, nome ou fala. Faltou dado, perguntar ao AE.
- Mostrar antes de gravar no CRM e pedir confirmação.
- Não abrir reunião com deck institucional. Preço só depois do custo do problema.
- Skill com status ⏳ ainda não existe: diga isso e use o handbook correspondente, se houver.
