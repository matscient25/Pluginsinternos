# Skills comerciais da Vektor · como usar

> Dados fictícios para treinamento. Skill-gabarito (mestre roteadora).

## O processo em 30 segundos
Funil: Qualificação → **Diagnóstico** → Proposta → Follow-up → Contrato → Handoff CS. Metodologia: Challenger (ensinar, adaptar, conduzir). Regra que mais pesa: nenhuma proposta sem **custo do problema em reais** confirmado no Diagnóstico. Handbooks em `04-handbooks/`.

## Mapa das skills
| Skill | Quando usar | Status |
|---|---|---|
| `vektor-como-usar` | Sempre primeiro (esta) | ✅ |
| `vektor-contexto` | Portfólio, ICP, personas, provas, vocabulário da Vektor | ⏳ a gerar de `contexto-empresa.md` |
| `vektor-metodologia` | Lente Challenger: elementos E1–E8, escala 0–3, critério de cada etapa | ⏳ a gerar de `02-lente/lente.md` |
| `vektor-qualificacao` | Primeira reunião: hipótese (Warmer), reframe, agendar o diagnóstico | ⏳ handbook pendente |
| `vektor-diagnostico` | Preparar, conduzir, registrar e revisar o Diagnóstico | ✅ |
| `vektor-proposta` | Montar e apresentar a proposta a partir do custo do problema | ⏳ handbook pendente |
| `vektor-negociacao` | Objeções de preço, piloto, concessões planejadas, contrato | ⏳ handbook pendente |
| `vektor-handoff-cs` | Passar contexto, critério de sucesso e riscos ao CS | ⏳ aguarda entrevista de CS |
| `vektor-avaliar-reuniao` | Nota de uma call pela lente e coaching do AE | ⏳ |

## Qual ler para cada tarefa
| Tarefa | Leia, nesta ordem |
|---|---|
| Preparar um diagnóstico | `vektor-diagnostico` (Preparar) → `vektor-contexto` → `vektor-metodologia` |
| Registrar um diagnóstico no CRM | `vektor-diagnostico` (Registrar) |
| Decidir se o negócio pode ir para Proposta | `vektor-diagnostico` (Revisar) |
| Cliente pediu preço por hora | `vektor-diagnostico` (objeções) → `vektor-negociacao` |
| Avaliar uma call para coaching | `vektor-avaliar-reuniao` → `vektor-metodologia` |
| Dúvida de portfólio ou ICP | `vektor-contexto` |

## Regras para todas as skills
- Nunca inventar número, nome ou fala. Faltou dado, perguntar ao AE.
- Mostrar antes de gravar no CRM e pedir confirmação.
- Não abrir reunião com deck institucional. Preço só depois do custo do problema.
- Skill com status ⏳ ainda não existe: diga isso e use o handbook correspondente, se houver.
