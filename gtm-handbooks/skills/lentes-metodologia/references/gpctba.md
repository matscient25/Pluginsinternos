# Lente pronta · GPCTBA/C&I

Fonte: HubSpot Sales. Qualificação consultiva para inbound, com foco em metas do cliente.

| Elemento | Evidência observável | Nota 3 quando | Perguntas-padrão |
|---|---|---|---|
| **G · Goals** | Metas do cliente | Meta com número e prazo | "Qual a meta deste ano?" |
| **P · Plans** | Plano atual para atingir | Plano descrito e lacunas claras | "Como pretendem chegar lá?" |
| **C · Challenges** | O que impede | Desafio ligado à meta | "O que pode impedir?" |
| **T · Timeline** | Quando precisa | Data com motivo | "Quando isso precisa estar resolvido?" |
| **B · Budget** | Recurso disponível | Faixa confirmada | "Que investimento faz sentido?" |
| **A · Authority** | Quem decide | Decisor envolvido | "Quem mais decide?" |
| **C · Negative Consequences** | O que acontece se falhar | Consequência dita pelo cliente | "O que acontece se não bater a meta?" |
| **I · Positive Implications** | O que acontece se der certo | Ganho dito pelo cliente | "E se bater?" |
